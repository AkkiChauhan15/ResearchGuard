Processing and retention

Reviews stay in browser memory and temporary server memory (up to one hour, with bounded capacity). Reloading the page starts a new session. Nothing is automatically saved to disk. Download an export to save your record. Searches and URLs go to the selected public source services. With an approved server configuration, AI actions send the input, context, or retrieved passages to the selected external model API. Provider data terms vary; do not submit private or unpublished material. No model credential is sent to the browser.
